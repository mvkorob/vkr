# Материалы по практике

[Отчёт по преддипломной практике](Отчет_преддипломная_практика.docx)
актуализирован по состоянию проекта на 26 ноября 2026 года, версия приложения 2.0.0.
Исходный срез: `7ac88e3`.

В отчёте обновлены:

- архитектура Flask, точки входа и серверный запуск через Gunicorn;
- схемы процессов, компонентов, функций и базы из 11 таблиц;
- результаты 67 тестов pytest и 10 предметных проверок;
- CSV/XLSX, JSON-обмен, уведомления и операции со справочником СЗИ;
- сведения о 58 снимках браузеров и устройств и 23 макетах;
- оглавление, номера рисунков и инструкции запуска.

DOCX открыт и преобразован в PDF с помощью LibreOffice для проверки оформления.
Получено 36 страниц. Проверены 29 пунктов оглавления, 11 рисунков в порядке
появления и 16 таблиц. Просмотрены страницы со схемами, проверками, заключением
и приложениями. Заголовки таблиц повторяются при переносе на следующую страницу.

Результаты приложения находятся в [протоколах](../docs/acceptance),
описание реализации в [пояснении кода](../docs/code_guide.md).
