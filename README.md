# InfoSec Desk - учебная система заявок

Приложение для регистрации и обработки заявок на обслуживание средств защиты информации. Текущая реализация: Python, Flask, SQLite.

Веб-система поддерживает три роли, ведение заявок, историю, комментарии, справочник СЗИ, 12 открытых страниц, административные разделы и выгрузку реестра в CSV/XLSX.

Опубликованная версия: https://infosec-service-desk-1.onrender.com/

[![Открыть сайт по QR-коду](docs/images/site-qr.png)](https://infosec-service-desk-1.onrender.com/)

Ветка `flask-migration` содержит переход с FastAPI на Flask. Обновление опубликованного сервиса выполняется отдельно.

## Запуск и проверки

```bash
python -m pip install -e ".[dev]"
python run.py init-db
python run.py serve
python -m pytest -q
python -m ruff check src tests run.py
```

После запуска открыть http://127.0.0.1:8000. Пароль администратора будет показан при первом локальном запуске; не использовать его в публичном режиме. Контрольные выгрузки будут добавлены следующими изменениями.

Текущая версия исходников: 2.0.0. Испытания в браузерах и размещение в интернете ещё не подтверждены.

## Учебная база

В `instance/demo.sqlite3` сохранена 501 учебная заявка: 251 закрытая и 250 новых.
Для локальной демонстрации запустите:

```bash
python run.py serve --db instance/demo.sqlite3
```

Учебные учётные записи: `admin`, `operator`, `employee`. Пароль для каждой: `DemoPass123!`.

## Существующая база

Перед переходом сохраните резервную копию базы и остановите старую версию приложения.
При запуске Flask добавляет недостающие таблицы в указанную SQLite-базу.
Пользователи, пароли, заявки, комментарии и журнал сохраняются.

Проверки и порядок запуска отдельных тестов описаны в `docs/verification.md`.
