# Примеры файлов обмена

## Реестр заявок

- `registry_all_501.csv` и `.xlsx`: 501 запись плюс строка заголовков.
- `registry_closed_251.csv` и `.xlsx`: 251 запись со статусом «Закрыта» плюс строка заголовков.

Образцы созданы из предметной функции чтения SQLite. При проверке веб-выгрузок
с ними сверены количество строк и последовательность номеров заявок.
Все значения CSV и XLSX, полученных через тестовый клиент Flask, также
сравнены между собой. Результаты: [проверка обмена](../docs/file_exchange_cases.md).

## Импорт СЗИ

[assets_import_example.json](assets_import_example.json) содержит один учебный
объект `LAB-EXCHANGE-01`. На копии учебной базы первый импорт добавляет объект,
повторный пропускает его по инвентарному номеру. Формат и ограничения описаны
в [руководстве по обмену файлами](../docs/file_exchange.md).
