## Как передать комплект

Скачайте [ZIP ветки main](https://github.com/mvkorob/vkr/archive/refs/heads/main.zip)
или создайте архив конкретного коммита:

```bash
git archive --format=zip --prefix=vkr-2.0.0/ --output=vkr-2.0.0.zip HEAD
```

Архив включает отслеживаемые исходники, учебную базу, документы и проверки.
Рабочая база, локальная `.venv` и настройки Git в него не входят.
Для сверки архива используйте SHA-256 и хеш исходного коммита.
