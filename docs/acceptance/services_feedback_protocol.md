# Услуги и сообщения посетителей

Администратор управляет услугами на `/admin/services`: задаёт код, название,
описание и категорию. Кнопки «Отключить» и «Включить» меняют признак активности.
Публичный каталог `/public/services` показывает только активные услуги;
административный список сохраняет и отключённые записи.

Форма `/feedback` доступна гостю. Она принимает имя, email, тему и сообщение.
Сервер проверяет поля и CSRF, затем сохраняет запись со статусом `new`.
Администратор открывает `/admin/feedback` и отмечает сообщение обработанным.
Статус меняется на `processed`, содержимое сообщения сохраняется.

## Результаты проверки

Исходный срез: [`4395165`](https://github.com/mvkorob/vkr/tree/4395165).
Использованы тестовый клиент Flask и временная копия учебной базы.
[11 результатов в JSON](services_feedback_results.json).

| Действие | Результат |
| --- | --- |
| Добавление услуги с неверным CSRF | Ответ 403 |
| Добавление услуги администратором | Услуга появилась в публичном каталоге |
| Отключение услуги | Услуга скрыта публично и сохранена в административном списке |
| Повторное включение | Услуга снова видна публично |
| Заявитель и специалист запрашивают разделы и операции управления | Ответ 403 |
| Гость отправляет обратную связь с неверным CSRF | Ответ 403 |
| Гость отправляет корректное сообщение | Запись сохранена со статусом `new` |
| Администратор открывает список сообщений | Тема и текст сообщения доступны |
| Администратор отмечает сообщение обработанным | Неверный CSRF отклонён; верный меняет статус на `processed`, текст сохранён |
| Отправка неверного email | Сообщение не записано |
| Сверка исходной базы | SHA-256 совпал |
