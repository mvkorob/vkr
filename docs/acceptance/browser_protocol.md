# Браузерная проверка опубликованного сайта

Материалы собраны 25 ноября 2026 года для сайта
[InfoSec Desk на Render](https://infosec-service-desk-1.onrender.com/).
Протокол описывает отображение публичных страниц: входа, справочной информации
и формы обратной связи.

[Все 58 снимков с подписями](browser_screenshots/README.md),
[метаданные и SHA-256](browser_screenshots/manifest.json),
[список файлов CSV](browser_screenshots/files.csv).

## Браузеры и устройства

| Среда | Материал | Что зафиксировано |
| --- | --- | --- |
| Chrome 153.0.8010.52, Linux | 24 снимка | Шесть страниц на четырёх размерах области браузера |
| Firefox 160.0.1, Linux | 24 снимка | Те же страницы и размеры области браузера |
| Safari, iPad | Один снимок | Страница входа, форма и боковая навигация |
| Safari, iPhone | Четыре снимка | Вход, фокус поля логина, прокрутка страницы и меню, категории |
| Яндекс Браузер, iPhone | Один снимок | Страница входа после прокрутки |
| Chrome, Windows | Два снимка | Вход и каталог услуг |
| Microsoft Edge, Windows | Два снимка | Вход и каталог услуг |

Chrome и Firefox на Linux снимались автоматически с эмуляцией области браузера:
1440 × 900, 1366 × 768, 768 × 1024 и 390 × 844 пикселя. Для каждого размера
открыты шесть страниц:

| Страница | Адрес |
| --- | --- |
| Вход | `/login` |
| О службе | `/public/overview` |
| Услуги | `/public/services` |
| Как подать заявку | `/public/submit` |
| Обратная связь | `/feedback` |
| Конфиденциальность | `/public/security` |

В метаданных всех 48 автоматических снимков зафиксированы подключение CSS,
готовность шрифтов и отсутствие горизонтального переполнения всей страницы.
Полноразмерный снимок включает содержимое ниже первого экрана.

Подробные наблюдения по каждому устройству собраны
в [протоколе устройств](devices_protocol.md).

## Вид интерфейса на устройствах

На Windows и iPad видна боковая навигация. На iPhone меню размещается
горизонтально над содержимым. Снимок категорий в Safari показывает меню после
прокрутки. Форма входа содержит отдельные поля логина и пароля и кнопку «Войти»;
на одном из снимков Safari видно выделение поля логина при фокусе.

## Проверка комплекта

При переносе в репозиторий проверены наличие всех 58 файлов, совпадение байтов
с исходным хранилищем и контрольные суммы. Размеры области браузера записаны
для автоматической съёмки; размеры самих изображений хранятся отдельно.
Каждый снимок связан с браузером, устройством, страницей и адресом сайта.

Функциональные сценарии приложения приведены отдельно в
[тест-плане](../test_plan.md) и [результатах HTTP-проверок](functional_results.json).
