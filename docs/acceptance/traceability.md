## Как пользоваться матрицей

1. Выберите код из ТЗ и откройте реализацию.
2. Посмотрите условия в тесте: роль, исходные данные и ожидаемый результат.
3. Откройте протокол: он содержит фактический способ проверки и результат.
4. Для интерфейса откройте связанный HTML-макет или исходный браузерный снимок.

Браузерный и аппаратный комплекты описывают внешний вид опубликованных страниц.
Функциональные протоколы описывают операции через Flask, HTTP и SQLite.
Проверка чистой установки выделена в самостоятельный сценарий.
