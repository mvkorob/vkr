## Повторение на Windows и Ubuntu

Из новой копии репозитория создайте окружение:

```powershell
# Windows
python -m venv .venv
.venv\Scripts\python.exe run.py
```

```bash
# Ubuntu
python3 -m venv .venv
.venv/bin/python run.py
```

1. Дождитесь установки зависимостей и сообщения с адресом сервера.
2. Сохраните выданный пароль администратора и откройте `http://127.0.0.1:8000`.
3. Войдите под `admin`, создайте заявку и откройте её карточку.
4. Назначьте исполнителя и пройдите статусы до «Закрыта».
5. Остановите сервер и повторите запуск той же командой.
6. Откройте карточку и проверьте исполнителя, даты и историю.

Служебные параметры `--db`, `--host`, `--port` позволяют выбрать базу и адрес.
`GET /health` проверяет доступ к SQLite. Рабочая база и `.venv` исключены из Git.

Для серверного запуска используется другой вход: Gunicorn и `wsgi:app`.
Его обязательные переменные и отдельная рабочая база описаны
в [руководстве по размещению](../deployment_render.md).
