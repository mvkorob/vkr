# Протокол проверки CSV и XLSX

Дата: 25.11.2026. Версия приложения: 2.0.0, коммит `022aad2`.
Среда: Linux, Python 3.10.12, Gunicorn 27.0.1, запросы HTTP к работающему серверу.
Проверка выполнена под ролью специалиста на отдельной копии `instance/demo.sqlite3`.

## Контрольный набор

В начале проверки база содержит 501 заявку, из них 251 со статусом `closed`.
Выгрузки выполнялись до создания новых заявок сценарного прогона.

| Выборка | Записей | Строк с заголовком | Первый номер | Последний номер |
|---|---|---|---|---|
| Без фильтра | 501 | 502 | З-000501 | З-000001 |
| `status=closed` | 251 | 252 | З-000501 | З-000001 |

Указанные количества получены для обоих HTTP-маршрутов: `/export.csv` и `/export.xlsx`.
Фильтр `status=closed` передавался в строке запроса каждого маршрута.

## Выполненные сверки

1. Получен ответ 200 на каждую из четырёх выгрузок.
2. CSV прочитан как UTF-8 с BOM, разделитель `;`. Проверены тип `text/csv` и заголовок `Cache-Control: no-store`.
3. Книги XLSX открыты через openpyxl. Проверены закрепление заголовка `A2` и наличие автофильтра.
4. Все значения ячеек CSV и XLSX совпали для полной и фильтрованной выборок.
5. Каждая HTTP-выгрузка совпала с соответствующим контрольным файлом в `samples`.
6. Количество уникальных номеров равно количеству заявок: 501 и 251. Дубли отсутствуют.
7. Русские названия, категории, статусы, ФИО и даты сохранены при чтении CSV и XLSX.
8. Полная выгрузка содержит 501 запись, включая запись сверх лимита 500 строк страницы реестра.

## Поиск и безопасное представление значений

После контрольных выгрузок через форму создана заявка с темой `=SUM(1,2)`.
Параметр поиска `q` вернул в CSV и XLSX только эту заявку.
В CSV тема начинается с апострофа; в XLSX значение ячейки имеет строковый тип `s`.
Таким образом, проверочное значение сохраняется как текст, а не исполняемая формула.

Заявитель получил 403 при обращении к обоим маршрутам экспорта.
Специалист получил полную и фильтрованную выгрузки после входа через форму.

## Результат

Проверены 501/251 запись в обоих форматах, совпадение с учебной базой и образцами,
отсутствие дублей, чтение русских значений, поиск и обработка строки с формулой.
Исходный файл учебной базы сохранён без изменений.

Данные проверки: [functional_results.json](functional_results.json), сценарии HTTP-07 и HTTP-11.
Автотест полного и фильтрованного реестра: `tests/test_requirements.py`.
