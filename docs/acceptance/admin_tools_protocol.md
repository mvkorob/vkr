# Настройки, аналитика и обмен СЗИ

Три раздела доступны администратору:

| Адрес | Назначение |
| --- | --- |
| `/admin/settings` | Название сайта, почта поддержки и время работы |
| `/admin/analytics` | Число записей в восьми таблицах |
| `/admin/data-exchange` | Скачивание JSON и форма импорта справочника СЗИ |

Настройки сохраняются в `application_settings`. Аналитика выполняет `COUNT(*)`
для заявок, пользователей, СЗИ, комментариев, обратной связи, вложений,
каталога услуг и аудита. Считаются все записи таблиц, включая неактивные
учётные записи и архивные СЗИ.

Обмен использует `GET /admin/assets.json` для выгрузки
и `POST /admin/assets.json` для импорта. Существующие инвентарные номера
пропускаются. Состав полей и ограничения описаны в [руководстве](../file_exchange.md).

## Результаты проверки

Исходный срез: [`34ff7c7`](https://github.com/mvkorob/vkr/tree/34ff7c7).
Использованы временная копия базы, тестовый клиент Flask и прямые запросы подсчёта.
[Девять результатов в JSON](admin_tools_results.json).

| Проверка | Результат |
| --- | --- |
| Заявитель и специалист запрашивают разделы и операции изменения | Ответ 403 |
| Сохранение настроек без верного CSRF | Ответ 403 |
| Сохранение трёх настроек администратором | Значения записаны и отображаются в форме |
| Сверка аналитики с SQLite | Восемь счётчиков совпали; заявок 501 |
| Открытие обмена и скачивание JSON | Страница доступна; выгружены два исходных СЗИ |
| Импорт без верного CSRF | Ответ 403 |
| Первый и повторный импорт примера | Добавлен один объект, повторный импорт пропускает его |
| Аналитика после импорта | Число СЗИ увеличилось до трёх |
| Сверка исходной базы | SHA-256 совпал |

Макеты администратора: [настройки](../mockups/admin_settings.html),
[аналитика](../mockups/admin_analytics.html), [обмен](../mockups/admin_exchange.html).
Они сформированы из текущих шаблонов. Отправка форм в статических макетах отключена.
