# Проверка сопровождения

Проверка выполнена 26 ноября 2026 года на временной базе после полного
HTTP-сценария заявки. [Результаты](maintenance_results.json).

| Действие | Результат |
| --- | --- |
| Создание резервной копии через SQLite Backup API | Копия открывается, `integrity_check=ok` |
| Проверка итоговой заявки в копии | Заявка сохранена со статусом `closed` |
| Попытка перезаписать существующий файл копии | Отклонена, файл сохранён |
| Чтение манифеста 2.0.1 | Формат проверен, версия сравнена с установленной 2.0.0 |
| Сверка исходной учебной базы | SHA-256 совпала |

Команды из корня проекта:

```bash
python run.py backup-db --db instance/infosec.sqlite3 --file backup.sqlite3
python run.py check-update --file release.json
```

`check-update` проверяет метаданные версии. Перед заменой исходников сохраняют
копию базы; после запуска проверяют `/health`, вход и ранее созданную заявку.
[Форматы файлов и параметры](../file_exchange.md).
