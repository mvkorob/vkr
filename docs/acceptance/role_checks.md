# Приёмка по ролям

Проверка выполнена 26 ноября 2026 года на исходном срезе
[`cd292fd`](https://github.com/mvkorob/vkr/tree/cd292fd).
Использованы временная копия учебной базы и тестовый клиент Flask.
Для каждой из трёх ролей вход выполнен через форму `/login` с её CSRF-токеном.
[12 результатов в JSON](role_results.json).

## Проверенные действия

| Роль | Действие | Наблюдаемый результат |
| --- | --- | --- |
| Гость | Открыть каталог услуг | Ответ 200 |
| Гость | Напрямую открыть пользователей, аудит, заявки и профиль | Ответ 303, перенаправление на `/login` |
| Заявитель | Войти, создать и открыть свою заявку | Вход успешен, заявка сохранена, карточка отвечает 200 |
| Заявитель | Открыть чужую карточку или отправить в неё комментарий | Ответ 404 |
| Заявитель | Открыть пользователей, аудит, настройки и CSV/XLSX-экспорт | Ответ 403 |
| Заявитель | Сменить статус через прямой POST-запрос | Ответ 403 |
| Специалист | Открыть заявки двух разных авторов и CSV/XLSX-экспорт | Ответ 200 |
| Специалист | Открыть пользователей, аудит и настройки | Ответ 403 |
| Специалист | Назначить себя и провести заявку до закрытия | Статус `closed`, сохранены четыре записи истории состояний |
| Администратор | Открыть семь административных страниц | Все отвечают 200 |
| Администратор | Добавить СЗИ через форму | Объект появился в справочнике |
| Администратор | Отправить настройки с неверным CSRF | Ответ 403 |

Семь административных страниц: `/users`, `/audit`, `/admin/services`,
`/admin/feedback`, `/admin/settings`, `/admin/analytics`, `/admin/data-exchange`.

Для проверки чужой карточки создан отдельный учебный автор. Его заявка
отличается от заявки основного заявителя. Поэтому отказ проверяет именно
разделение по авторству, а не обращение к отсутствующей записи.

## Сохранность данных

Статус и количество записей истории проверены прямыми запросами SQLite.
SHA-256 исходного файла `instance/demo.sqlite3` до и после сценария совпал.

Детальные операции администратора разобраны в протоколах
[пользователей и аудита](users_audit_protocol.md), [СЗИ](assets_protocol.md),
[услуг и обратной связи](services_feedback_protocol.md),
[настроек и обмена](admin_tools_protocol.md).
Полный перечень адресов: [матрица маршрутов](../route_matrix.md).
