# Сквозной пример обработки заявки

Сценарий выполнен 26 ноября 2026 года через настоящий локальный HTTP-сервер
с кодом среза `f194e05`. Для каждой роли выполнен вход через форму.
Рабочие данные находились во временной копии учебной базы.
[Результаты](user_scenario_results.json).

| Шаг | Действие | Полученный результат |
| --- | --- | --- |
| 1 | Вход `employee`, `operator`, `admin` | Три сеанса открыты |
| 2 | Заявитель создаёт обращение и выбирает СЗИ | Сохранена заявка З-000502 |
| 3 | Специалист назначает себя | Исполнитель operator, статус «В работе» |
| 4 | Заявитель и специалист добавляют комментарии | Сохранены два сообщения |
| 5 | Заявитель прикрепляет result.txt | Файл скачан, байты совпали |
| 6 | Специалист решает и закрывает заявку | Даты решения и закрытия заполнены |
| 7 | Проверка истории | «Новая» → «В работе» → «Решена» → «Закрыта» |
| 8 | Уведомления, CSV и аудит | Уведомление видно заявителю, CSV содержит заявку, аудит открыт администратору |

Статус, даты, комментарии и история дополнительно проверены запросами SQLite.
Исходная база после сценария сохранила контрольную сумму.
Созданная заявка относится к временному прогону; исходная учебная база содержит 501 заявку.
