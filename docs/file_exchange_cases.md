# Проверка файлового обмена

Проверки выполнены на коде версии
[`914bdba`](https://github.com/mvkorob/vkr/tree/914bdba).
Использованы тестовый клиент Flask и функции `import_assets` и `export_assets`.
Все операции выполнялись на временной копии учебной базы.

[Результаты 17 проверок в JSON](acceptance/file_exchange_results.json)
содержат сценарий, результат и проверенные значения.

## Реестр заявок

| Сценарий | Результат |
| --- | --- |
| Экспорт без фильтров | 501 заявка и строка заголовков в каждом формате |
| `status=closed` | 251 заявка и строка заголовков в каждом формате |
| `q=501` | Одна заявка и строка заголовков на этой учебной базе |
| Сравнение CSV и XLSX | Все значения строк совпали после чтения файлов |
| Сравнение с образцами `registry_all_501` и `registry_closed_251` | Количество строк и последовательность номеров совпали |
| Запрос CSV, XLSX и JSON под заявителем | Ответ 403 |

Для CSV также проверено наличие BOM. XLSX прочитан через openpyxl,
сравнение выполнено по значениям ячеек.

## Справочник СЗИ

| Сценарий | Результат |
| --- | --- |
| Экспорт через веб-маршрут и `export_assets` | Одинаковый JSON с двумя исходными объектами |
| Первый импорт [файла-примера](../samples/assets_import_example.json) через сайт | Добавлен один объект |
| Повторный импорт того же файла | Добавлено 0, пропущен один объект |
| Импорт с неверным CSRF-токеном | Ответ 403 |
| Повреждённый JSON | Ошибка, число объектов не изменилось |
| Неверная метка формата | Ошибка, число объектов не изменилось |
| Лишнее поле объекта | Ошибка, число объектов не изменилось |
| Повтор номера внутри файла | Ошибка, число объектов не изменилось |
| Корректный первый объект и пустое имя второго | Ошибка, первый объект также не добавлен |
| Более 1000 объектов | Ошибка, число объектов не изменилось |
| Файл больше 2 МиБ | Ошибка, число объектов не изменилось |

Проверки неверных файлов выполнены прямым вызовом `import_assets`.
Первый и повторный импорт примера выполнены через форму веб-маршрута.
SHA-256 исходного файла `instance/demo.sqlite3` до и после всех операций совпал.

## Как повторить основные сценарии

1. Создайте отдельную копию учебной базы и укажите её через `--db` при запуске.
2. Под специалистом выгрузите реестр в CSV и XLSX без фильтров и со статусом «Закрыта».
3. Под администратором откройте «Обмен справочником СЗИ» и выгрузите JSON.
4. Импортируйте `samples/assets_import_example.json`, затем повторите импорт.
5. Проверьте сообщение о добавлении при первом импорте и пропуске при повторном.

Автоматические проверки импорта, атомарности и резервирования:

```bash
python -m pytest -q tests/test_exchange_maintenance.py
```

Проверки прав и выгрузки через Flask находятся в `tests/test_web.py`.
Описание полей и команд: [обмен файлами](file_exchange.md).
