# Версия InfoSec Desk 2.0.0

Дата записи: 2026-11-25.
Репозиторий: [mvkorob/vkr](https://github.com/mvkorob/vkr), ветка `main`.
Версия зафиксирована в `pyproject.toml` и `src/infosec_desk/__init__.py`.

## Состав

- Flask-приложение с тремя ролями, заявками, комментариями и вложениями.
- SQLite: 11 таблиц, учебная база с 501 заявкой и тремя учётными записями.
- CSV/XLSX: полный реестр на 501 запись и фильтрованный на 251 закрытую заявку.
- JSON-обмен справочника, уведомления, каталог услуг и настройки службы.
- WSGI-точка входа, зависимости Gunicorn, Blueprint Render и Dockerfile.
- Инструкция запуска для Windows и Ubuntu, QR-код опубликованного сайта.

## Запуск локальной демонстрации

```bash
python run.py serve --db instance/demo.sqlite3
```

В Ubuntu используется `python3`. Адрес: http://127.0.0.1:8000.
Учебные логины: `admin`, `operator`, `employee`; пароль: `DemoPass123!`.
Порядок работы с основной базой, восстановлением пароля и резервными копиями указан
в [README](../README.md).

## Подготовка серверного запуска

В WSGI используются отдельная копия учебной базы и секреты из окружения.
Известные учебные пароли заменяются. Порядок создания сервиса и его проверки
описан в [deployment_render.md](deployment_render.md).
