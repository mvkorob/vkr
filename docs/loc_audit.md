## Методика

Учитываются отслеживаемые Git файлы с расширениями `.py`, `.html`, `.css`, `.sql`.
Приложение включает `src/`, `sql/`, `run.py` и `wsgi.py`. Тесты и инструменты
подсчитываются отдельными категориями. В расчёт входят только файлы приложения,
Python-тесты и Python-инструменты; сторонние библиотеки, документация, макеты,
SQL-фикстуры тестов и виртуальное окружение исключены.

Пустые строки и отдельные строки комментариев Python/SQL исключаются.
Комментарии CSS и HTML удаляются с сохранением границ строк.
Строки документации Python и строковых литералов учитываются.
Метрика описывает физические строки файлов; перенос выражения на несколько строк
влияет на результат. Это измерение объёма файлов репозитория.

## Повторение расчёта

```bash
python tools/count_loc.py
python tools/count_loc.py --json
```

[Построчный по файлам результат](loc_audit.json) содержит пути, категории,
количество строк каждого файла и итоговые суммы.
