# План и результаты проверки версии 2.0.0

Дата: 25.11.2026. Проверяемая версия приложения: `022aad2`.

## Среда и методы

- Автотесты: pytest, временные SQLite-базы; CI на Windows и Ubuntu с Python 3.10, 3.12 и 3.13.
- Сценарные проверки: Linux, Python 3.10.12, Gunicorn 27.0.1, HTTP через `127.0.0.1`.
- Данные сценариев: отдельная временная копия учебной базы с 501 заявкой и тремя ролями.
- Проверка предметных функций: `python tools/offline_check.py`.
- Интерфейс: локальный Chrome при ширине 1440 и 390 пикселей, просмотр форм и действия редактора пользователей.

В сценарном прогоне пользователи входили через форму, передавали CSRF-токены,
создавали записи и скачивали файлы с работающего сервера. Результаты ответов сверялись
с содержимым временной базы. После завершения проверены целостность, внешние ключи
и сохранность исходного файла учебной базы.

## Сценарии и фактические результаты

| Код | Проверка | Результат |
|---|---|---|
| HTTP-01 | Запуск Gunicorn и `/health` | Сервер запущен, ответ 200 |
| HTTP-02 | Публичные страницы, вход и обратная связь | 12 справочных страниц и две формы открываются с кодом 200 |
| HTTP-03 | Гость открывает закрытые разделы | Перенаправление 303 на `/login` |
| HTTP-04 | Обратная связь с CSRF и без него | Без токена 403; корректное сообщение сохранено |
| HTTP-05 | Вход администратора, специалиста и заявителя | Три сессии успешно созданы через HTTP |
| HTTP-06 | Права на административные разделы и экспорт | Семь страниц доступны администратору; ограничения специалиста и заявителя соблюдаются |
| HTTP-07 | Полный и фильтрованный CSV/XLSX | 501 и 251 запись; совпадение форматов и файлов `samples` |
| HTTP-08 | Создание пользователя и чужая заявка | Пользователь создан; чужая карточка возвращает 404 |
| HTTP-09 | Создание заявки, комментарии, вложения и ограничения | Заявка создана, два комментария записаны; вложение скачивается владельцем; чужой доступ блокируется |
| HTTP-10 | Назначение, решение и закрытие | Четыре состояния в истории; даты решения и закрытия заполнены |
| HTTP-11 | Поиск при экспорте и строка с формулой | Найдена одна запись; CSV экранирует начало формулы, ячейка XLSX имеет строковый тип |
| HTTP-12 | JSON-импорт | Новая запись добавлена; повтор не создал дубль; неверный формат не изменил справочник |
| HTTP-13 | Настройки, уведомления, выход | Настройки отображаются, уведомления прочитаны, после выхода закрытые страницы требуют входа |
| HTTP-14 | База после сценариев | `integrity_check`: `ok`; нарушений внешних ключей нет |

Подробные результаты: [functional_results.json](acceptance/functional_results.json).

## Автоматизированные проверки

```bash
python -m pytest -q
python -m ruff check src tests tools run.py wsgi.py
python tools/offline_check.py
```

Состав 67 тестов приведён в [verification.md](verification.md).
Десять проверок предметных функций записаны в [verification_offline.txt](verification_offline.txt).
Отдельные тесты проверяют запуск WSGI, замену учебных паролей, проверку секретов,
сохранение данных при повторном старте и защиту исходной базы.
