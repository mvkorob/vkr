# Проверка программного обеспечения

Для запуска тестов не нужны реальные учетные записи. Каждый тест работает со временной SQLite-базой.

## Запуск

Из папки с `run.py` выполните:

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
```

Результат для проверенной локально редакции: **42 tests passed**. При ошибке pytest показывает имя теста и причину несоответствия.

Запуск одного файла: `python -m pytest tests/test_service.py -q`.
Для подробного вывода: `python -m pytest -v`.

Итого: **42 тестов**.

## Что проверяется вручную

1. Выполнить `python run.py seed-demo --db instance/demo.sqlite3`.
2. Запустить `python run.py serve --db instance/demo.sqlite3`.
3. Открыть `http://127.0.0.1:8000` и войти под логином `admin`, пароль `DemoPass123!`.
4. В разделе «Пользователи» изменить ФИО или роль тестовой записи и сохранить изменения.
5. В разделе «Средства защиты» исправить название СЗИ и исключить его из активного списка.
6. Перейти к заявке, назначить исполнителя, перевести ее в статусы «В работе», «Решена», «Закрыта».
7. Проверить отображение дат решения и закрытия, логина исполнителя и русских статусов в истории.
8. После завершения остановить сервер Ctrl+C.

Удаление учетной записи выполняется как ее отключение, удаление СЗИ - как исключение из действующего списка. Это сохраняет историю заявок и связи в БД.
